# WEMIN TV para Samsung

Repositório de distribuição do WEMIN TV para Smart TVs Samsung com Tizen 5.5 ou superior.

## Download

Baixe o pacote `.wgt` na [última release](https://github.com/Shicknovz/WEMIN_TV/releases/latest).

## Instalação

Use o [Apps2Samsung](https://apps2samsung.com/) com a TV e o computador ou celular na mesma rede. Ative o modo desenvolvedor na TV e siga o fluxo de certificado e instalação do instalador. O pacote é distribuído sem assinatura para ser assinado para a TV de destino.

Este repositório contém os arquivos de distribuição.
